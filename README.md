# fiorencia
An experimental C++ game built for learning, rapid iteration, and open-source experimentation
Fiorencia is a small, evolving game project developed alongside my college programming coursework. I wanted a practical way to experiment with C++, change game mechanics quickly, observe the results, and learn how programming concepts work in a real project.

This is both a game and a learning sandbox. It is a work in progress, and its code and mechanics will continue to evolve as I learn.

## Why This Project Exists

I'm taking a college coding course and wanted a project that would let me experiment beyond individual classroom exercises.

Rather than only writing isolated programs, I'm using Fiorencia to explore how programming concepts fit together in a larger application, including:

- Game state and player attributes
- Character classes and progression
- Economy, resources, and balancing
- Game loops, decisions, and conditional logic
- Saving and loading player progress
- Testing changes and observing their effects

My goal is to learn by building, experimenting, making mistakes, and improving the project over time.
